# Хендофф в разработку: Свободный диалог и не-блокирующее исследование

**Статус:** готово к работе · **Дорожка:** серверное ядро (Go) · **Исполнитель:** локальный Claude Code
**Дата:** 2026-08-21

## Одно предложение

Парсер перестаёт отбивать невокабулярный ввод («так не получится») — любая
попытка приземляется в фикшен; плюс генератор Divinity-аффордансов из read-scope.

## Почему это, почему сейчас

Живой прогон уткнулся в тупик «так не получится» — исследование рубится на корню.
Это самый заметный разрыв между текущим движком и желаемым Divinity-ощущением, и
он чистый домен (Go), без внешних зависимостей и без клиента. Результат сразу
видно в консольном `--nl`-прогоне.

## Definition of Done

- Невокабулярный ввод даёт **свободную пробу** (фикшен-отклик), не отказ.
- Проба, совпавшая с авторской целью/гейтом, резолвится ядром; несовпавшая —
  только повествование, канон не меняется (проверено тестом до/после).
- Генератор аффордансов отдаёт 2–4 leak-безопасных варианта из read-scope, с
  опциями-проверками (класс + порог); leak-тест зелёный.
- Консоль принимает **номер или свободный текст** единым путём.
- `go test ./...` зелёный; `e2e/architecture_test.go` не тронут.

## Риск-заметка

Фаза 2 (разрешение пробы) граничит с consistency-guard из ADR-0003 — но полный
guard в этот объём не входит: здесь достаточно «проба не меняет канон и не выдаёт
факт дела». Guard по состоянию — отдельная спека, не блокирует эту работу.
