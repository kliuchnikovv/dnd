# Архитектурные решения (ADR)

Индекс решений по проекту. ADR фиксирует **выбор с последствиями**: контекст,
рассмотренные варианты, принятый и почему. Спеки и планы — это уже *как* делать
принятое; они сгруппированы под своими ADR ниже.

Статусы: **Предложен** — на подпись · **Принят** — действует · **Заменён** —
перекрыт более поздним · **Устарел** — снят.

## Работы под решениями

Спека — дизайн, план — пофазный бриф для локального Claude Code. Живут в
`docs/superpowers/specs/` и `docs/superpowers/plans/`.

### Фундамент (до ADR)

- **M1a — консольный детектив**: [спека](../superpowers/specs/2026-08-18-m1a-console-detective-design.md) ·
  [план](../superpowers/plans/2026-08-18-m1a-console-detective.md) ·
  [статус](../m1a-status.md). Ядро, «Порог», два дела, CLI, тесты. База, на
  которой стоит всё остальное.

### Под ADR-0001 (слои и доверенное ядро)

- **Капабилити-таблица ролей**: [спека](../superpowers/specs/2026-08-21-role-capabilities-design.md) ·
  [план](../superpowers/plans/2026-08-21-role-capabilities-plan.md).
  Сердцевина варианта А: read scope (least-privilege) + proposal kind на роль;
  `RequiresStrictOutput` выводится из реестра, никто из LLM не мутирует напрямую.
- **API мутаций ядра** (линчпин): [спека](../superpowers/specs/2026-08-21-core-mutation-api-design.md) ·
  [план](../superpowers/plans/2026-08-21-core-mutation-api-plan.md).
  Единственная валидируемая граница состояния: `Apply` (команды) + `ProposeMutation`
  (мутации); капабилити-гейт над доменом + инвариант-гейт в ядре. Разблокирует
  канон Мастера, куратора и runtime read-scope.
- **Диалоговый актёр + Мастер-власть**: [спека](../superpowers/specs/2026-08-21-dialogue-actor-master-authority-design.md) ·
  [план](../superpowers/plans/2026-08-21-dialogue-actor-master-plan.md).
  Актёр с памятью не расширяет мир; мир расширяет Мастер по запросу
  (propose-validate). Прямое приложение принципа ADR-0001.
- **Порог от позиции** (action item №3): [спека](../superpowers/specs/2026-08-21-difficulty-from-position-design.md) ·
  [план](../superpowers/plans/2026-08-21-difficulty-from-position-plan.md).
  Ядро ставит сложность несудимого действия функцией от позиции; рассказчик в
  выборе порога не участвует. Закрывает развилку импровизации из живой катки.
- **Инвентарь и предъявление**: [спека](../superpowers/specs/2026-08-21-inventory-and-present-design.md) ·
  [план](../superpowers/plans/2026-08-21-inventory-plan.md).
  Предмет — ключ к существующим примитивам (гейт, факт, tool); `present` —
  детерминированный ключ, эффект авторский. (Пересекается с ADR-0001 по границе
  мутаций.)

### Под ADR-0003 (модель угроз и свободный диалог)

- **Свободный диалог и не-блокирующее исследование** (№1, №3): [спека](../superpowers/specs/2026-08-21-free-dialogue-nonblocking-design.md) ·
  [план](../superpowers/plans/2026-08-21-free-dialogue-nonblocking-plan.md).
  Парсер не блокирует (свободная проба вместо тупика); Divinity-аффордансы из
  read-scope с тегами проверок; номер или свободный текст.

### Под ADR-0002 (журнал действий)

- **Журнал действий и WAL** (консольная реализация): [спека](../superpowers/specs/2026-08-21-action-log-design.md) ·
  [план](../superpowers/plans/2026-08-21-action-log-plan.md).
  Журнал команд (правда реплея) + аудит-поток; запись до обработки, реплеер,
  версия ядра. Форма таблиц под Postgres, собирается локально без сервера.

### Под ADR-0003 (свободный диалог)

- **Свободный диалог и не-блокирующее исследование** (action items №1, №3):
  [спека](../superpowers/specs/2026-08-21-free-dialogue-nonblocking-design.md) ·
  [план](../superpowers/plans/2026-08-21-free-dialogue-nonblocking-plan.md).
  Исход-тупик убирается: невокабулярный ввод приземляется свободной пробой и
  доезжает до авторского содержимого через ядро. Плюс детерминированный
  leak-безопасный набор подсказок и консольный UX «номер или слова».
