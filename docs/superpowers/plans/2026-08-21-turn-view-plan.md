# Протокол turn-view. План для Claude Code

Дата: 2026-08-21 (ред. 2 — две оси + surfacing)
Дизайн: `docs/superpowers/specs/2026-08-21-turn-view-design.md`
ADR: `docs/adr/0004-client-and-turn-view.md`
Исполнитель: локальный Claude Code (Go 1.26, `go test ./...`)

## Инварианты (во всех фазах)

1. Обе оси — дескрипторами: меры/резолюция от правила, панель от сценария; ни «grit», ни «casebook», ни «d20» как понятий в структуре нет.
2. Что показать сейчас — решает сервер (`Surface`), не клиент.
3. Нет `truth`/гейтнутого-неизвестного; `view` над доменом; `architecture_test` зелёный.
4. `go test ./...` зелёный после каждой фазы.

## Фаза 1 — Типы (дескрипторы)

* Пакет `view`: `TurnView`, `Meter` (Label/Kind/Value/Max/Surface), `Resolution` (Terms/Target/Margin/Outcome), `Option`, `Panel`/`Section`/`Slot`/`PanelItem`, `Block`, `Who`, `MapView`, `Ending`, `Version`. JSON-теги.
* Тесты: JSON round-trip; опциональные (`Resolution`,`Map`,`Objective`,`Ended`) опускаются.

## Фаза 2 — Сборка из ядра/правила/сценария

* `view.Build(...)`: Scene; Meters — от правила (метки+значения+`Surface` из состояния: ранен→показать, часы близки→показать); Resolution — из `res.Res` как термы+исход; Options — `g.Affordances(with)`+слова; Objective — панель сценария (для детектива: факты+источники+confidence в Sections, слоты who/how/when/why); Participants; Ended (сценарное условие).
* Тесты: сбор из «Гавани»; `Surface` меняется вслед за состоянием; без моделей Narration пуст, меры/резолюция/панель полны.

## Фаза 3 — Консоль печатает из вида (только Surface)

* `cli/render.go`: печать из `TurnView`; на экран — только `Surface:true` меры и панель. Существующие render-тесты зелёные или обновлены осознанно.
* Тест: скрытая мера не печатается; всплывшая печатается.

## Фаза 4 — Опции как токены

* Стабильный `Token` на `Option`; ввод номера/токена → тот же интент тем же путём.
* Тест: токен даёт тот же интент, что развёрнутая опция.

## Фаза 5 — Шов агностичности + leak

* Тест «вид не знает правила/сценария»: нет захардкоженных меток мер, панель обобщённая (детектив наполняет её данными, не формой). В духе `architecture_test`.
* Leak-тест: в `TurnView` нет `truth` и гейтнутого-неизвестного.
