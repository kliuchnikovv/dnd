## 2. Дыра: `survey`, пропы и развязка

**Ни одного упоминания в коде.** `grep -ri "props\|survey\|summation\|aftermath\|cold_case"` по Go и JSON не даёт ни одного попадания в предметной области.

| Требование брифа | Статус |
|---|---|
| Таблица `scene_props (id, node_id, name, kind, tags[])` | ❌ типа нет |
| Команда `survey` | ❌ нет; ближайшее — `Render.Scene`, печатает сущности узла |
| Проп никогда не держит факт — «по типу, а не по договорённости» | ❌ запрета нет, потому что нет типа |
| Теги пропа из закрытого словаря модификаторов | ❌ |
| `facts[].summation_clause` | ❌ поля нет |
| `case.aftermath`, `case.cold_case_text` | ❌ полей нет |

### Следствие 1: DoD не выполнен

Бриф: «пройти дело от первой сцены до **прочитанной развязки**». Фактический
вывод на верном обвинении — `cli/repl.go:119`:

```
Обвинение верно. Попыток: 1.
```

Прогон обрывается на строке статуса. Оба walkthrough-файла заканчиваются
`accuse` → четыре токена → `quit`.

### Следствие 2: список сцены — карта решения

Ровно тот провал, о котором предупреждает бриф. Измерено:

| Дело | Сущностей | Из них холдеров | Пропов |
|---|---|---|---|
| «Гавань» | 9 | **9** | 0 |
| «Форт Мерло» | 23 | **21** | 0 |

Игрок в `n_warehouse` видит две строки, и обе — решение. Требование «3–5 пропов
на узел, не меньше, чем холдеров» нарушено в каждом узле обоих дел.

### Следствие 3: 5 из 13 тестов брифа не существует

Нет: `survey` печатает пропы наравне с холдерами · пропов не меньше, чем
холдеров · ни один тег пропа не вне словаря · проп не может быть холдером ·
развязка собирается только из клауз. Плюс «свободные команды не двигают часы,
200 прогонов» покрыт лишь точечно (`TestLookNeedsNothing`,
`TestFlavourAndSoftVerbsNeverRoll`, `TestTheorizeIsRecordedAndCostsNothing`).

## 6. Инварианты, снятые осознанно

Оба документа писались под «M1a = ноль LLM». Репозиторий ушёл дальше, и это
видно в самих тестах, а не только в коде.

| Инвариант документа | Что в коде |
|---|---|
| «Ни одного вызова LLM» | Заменён на границу: `TestPureLayersDoNotDependOnLLM` требует, чтобы `core`, `rules`, `store`, `dice`, `cases` не тянули `llm` и `net/http`. Пакеты `llm/`, `intent/`, `actor/` существуют и звонят моделям |
| «Пустой go.mod» | Заменён на allowlist: `TestDependenciesAreAllowlisted`, разрешён `anthropic-sdk-go` |
| «Дневников сущностей в M1a нет намеренно» | Реализованы целиком, вместе с голосом, расположением и незакрытыми темами |
| «Естественного языка нет» | Есть: `intent/parser.go` — strict tool use, `actor/` — NPC говорят прямой речью |

Это не ошибки, а сдвиг вехи. Но пока документы утверждают обратное, они
описывают не этот репозиторий.

## Гейт

**Не пройден и не может быть пройден в текущем виде.** Критерий «понятно ли,
что делать дальше, без подсказки» бриф объявляет измеримым только через
`survey` с пропами. `survey` нет, пропов нет, камуфляж нулевой — значит
единственный измерительный инструмент этого критерия отсутствует, а список
сцены прямо выдаёт граф. Критерий «ощущается ли прочитанная развязка своим
выводом» нечем проверять по той же причине: развязки нет.
